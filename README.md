# 🎨 Design Philosophy

> **Great software isn't only about functionality. It's about experience.**

My design process:

```text
             💡 IDEA
                │
                ▼
        ┌───────────────┐
        │    RESEARCH   │
        └───────┬───────┘
                │
                ▼
        ┌───────────────┐
        │    UI / UX    │
        └───────┬───────┘
                │
                ▼
        ┌───────────────┐
        │  DEVELOPMENT  │
        └───────┬───────┘
                │
                ▼
        ┌───────────────┐
        │    TESTING    │
        └───────┬───────┘
                │
                ▼
        ┌───────────────┐
        │     SHIP      │
        └───────────────┘
```

### ✦ Design Principles

```text
Minimal
Responsive
Interactive
Accessible
Consistent
Purposeful
```

I especially enjoy combining **clean interfaces with subtle motion**, rather than adding animation simply for decoration.
